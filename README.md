# Rocket League Mobile

An original 3D car-football game for iPhone, inspired by the car-soccer genre.

## Planned features
- 3D arena and ball physics
- Drivable cars and rocket boost
- Touchscreen controls
- Goals, scoreboard, and match timer
- Local matches against AI opponents

This is an independent project and is not affiliated with or endorsed by Psyonix or Epic Games. It will use original code and assets.
